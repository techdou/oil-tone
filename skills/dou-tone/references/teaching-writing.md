# 教学与教育材料

适用于教案、说课稿、教学设计、课堂活动、教师汇报、学习任务、评价设计和面向学生的教学文案。

## 核心原则

文本要同时满足学科准确性、学段适配性和课堂可执行性。不要用宏大教育口号代替具体教学设计。

## 规则

- 根据学生年龄、已有知识和任务难度选择术语与解释方式。
- 教学目标写可观察的学习结果，避免只写“提升素养、培养能力、激发兴趣”而没有具体行为。
- 活动设计写清教师做什么、学生做什么、使用什么材料、产生什么学习证据。
- 互动问题应服务于概念理解、迁移或评价，不为了“活跃课堂”机械插入问答。
- 对 AI、算法等概念避免误导性拟人化或绝对化表达。
- 课堂语言自然、可说出口；教案和说课稿则保持必要的专业与规范。
- 评价要和目标对应；没有量表、题目或观察证据时，不虚构评价结果。
- 引用课程标准、政策或教材内容时，保持版本、年份和原意准确。

## 结构参考

按材料选择：学情 / 教材分析 / 目标 / 重难点 / 教学过程 / 评价 / 作业与拓展；或情境导入 / 任务驱动 / 探究 / 练习 / 迁移 / 总结。

不强制所有教学材料使用同一模板。
