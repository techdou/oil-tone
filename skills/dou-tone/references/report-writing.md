# 正式报告与文书

适用于工作总结、阶段汇报、建设方案、实施方案、调研报告、申请材料、情况说明、复盘材料、甲方交付文档等。

## 目标

优先保证规范、清楚、可执行、口径一致。正式不等于堆砌套话，也不等于故意使用复杂长句。

## 结构

根据材料选择真实结构，不强行套模板。常见关系包括：

- 背景 / 依据 → 现状 → 问题 → 原因 → 措施 → 计划。
- 目标 → 建设内容 → 实施路径 → 交付物 → 风险 / 边界。
- 本期工作 → 完成情况 → 问题 → 下一步。

若原文只是短说明，不为了“像报告”强行扩展成完整六段式。

## 规则

- 标题直接说明内容，不制造宣传感。
- 一级、二级标题必须存在真实层级关系；同级标题保持语法形式尽量一致。
- 明确责任主体、动作、对象、结果和时间口径。材料没有责任人或节点时不得补写。
- 同一概念统一称谓；确需使用简称时首次给出全称和简称。
- 数字、单位、金额、时间、百分比保持原口径；发现前后冲突时提示核对。
- “完成、上线、交付、通过、实现”等结果性动词必须有材料依据。
- 区分“计划、拟、预计、目标”和“已经完成”，不得把未来安排润色成既成事实。
- 对风险、限制和未完成事项使用中性准确表达，不为了显得积极而弱化问题。

## 避免

- “全面赋能、打造新生态、形成强大合力、迈上新台阶”等没有具体信息的表述。
- 每段末尾追加“具有重要意义”“为后续奠定基础”。
- 为显得正式而重复“进一步、持续、不断、切实、全面”。
- 把方案目标写成已经实现的成果。

## 输出

用户只要求润色时，保留原有章节层级和事实顺序；只有 L3 及以上才允许明显重组。
